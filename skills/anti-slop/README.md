# Anti-Slop

Edit a draft with a light touch, or learn which patterns make it feel generic. The skill preserves meaning and the writer's voice. It does not determine whether AI wrote something or fact-check every claim.

## Use in Maker Labs

Supply a draft in your chat and ask:

- "Use Anti-Slop to edit this email. Keep my blunt tone."
- "Flag the generic patterns in this article without rewriting it."
- "Give this draft a light Anti-Slop pass. Preserve all quotes and technical terms."

Editing returns the complete revised draft and a short account of the changes. Flagging returns quoted findings and brief repair suggestions. If the writing is already clear, the skill can leave it alone.

No connectors or separate editing skill are required. File reading depends on the tools available in your chat; pasting text works too. If the edit goes too far, identify the lines to restore and ask for a lighter pass. Your explicit style preferences control.
