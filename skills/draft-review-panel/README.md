# Draft Review Panel

Paste a draft or provide an accessible document and ask: "Use Draft Review Panel to review this."

The skill reads the draft, explains its choice of three to five reviewers, and returns up to five specific changes plus what to preserve. It adapts to articles, personal essays, stories, sales pages, proposals, reports, and messages. You do not need writing samples, a style guide, or any account connection. Add an audience or goal only if you want to clarify something the draft does not establish.

Reviews preserve the voice in your draft. They do not automatically rewrite, edit the source, publish, or send anything. Numerical scoring and saved review files are optional requests.

Independent subagents run when the host supports them. Limited capacity uses batches; unavailable subagents use disclosed sequential passes. The main agent combines the findings. Model agreement does not verify facts or predict real reader behavior. Current factual checks depend on available research tools; unresolved claims are labeled. A URL must expose the full requested text, or you will be asked to paste the missing content.

Examples:

- "Review this personal essay. I want the ending to feel earned."
- "Review this tutorial for beginners and check for missing steps."
- "Review this proposal for the person approving the budget."
- "Suggest a panel for this draft and wait before running it."

Evaluation cases are in [evals/evals.json](evals/evals.json). They are test inputs and acceptance criteria, not required setup for readers.
