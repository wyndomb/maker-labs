# Offer Check

A quick look at the offer before working on the page. Adapted from the value equation in Alex Hormozi's *$100M Offers*.

Perceived value goes up when the outcome is clearer and more believable, and goes down when the result is slow or takes a lot of effort. Score each lever 1 to 5 using only the offer brief:

| Lever | Ask | Weak sign |
| --- | --- | --- |
| **Outcome** | Can a buyer say what will be different for them afterward? | Only features or activities are listed |
| **Believability** | Is there proof this works for someone like the buyer? | Proof is only about the seller's audience or credentials |
| **Time to result** | How soon does the buyer see a first result? | Nothing visible until the very end |
| **Effort for the buyer** | How much work, risk, or learning does it ask of them? | The buyer does most of the work, or the risk is all theirs |

Report the lowest lever in one or two sentences, with the change that would raise it. For example: "Believability is the weak lever. Every proof point is about you, not a client. One client quote near the form would do more than any copy change."

Only suggest offer changes the user could actually make, like collecting proof, adding a first-week milestone, stating a refund policy they already honor, or clarifying the deliverable. Never suggest inventing bonuses, guarantees, or deadlines. If the offer looks sound, say so in one line and move on.
