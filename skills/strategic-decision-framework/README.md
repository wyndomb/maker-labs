# Strategic Decision Framework

Turn a business choice into a brief that connects evidence, tradeoffs, and a next action.

## Use in Maker Labs

Supply the decision, options, goal, deadline, constraints, and any relevant customer, product, pricing, or strategy material. Pasted notes work when files or connectors are unavailable.

Try "Compare these priorities and recommend a path using the attached evidence." For analysis without a recommendation, say "Show the decision tension and leave the choice to me."

Focused Mode uses three to five useful lenses. Full Mode uses all ten only when explicitly requested. Independent review is a separate option: ask "Use an evidence reviewer and a challenge reviewer." It depends on available, authorized subagents; otherwise the skill performs sequential checks and says so.

The brief includes evidence and assumptions, constraint fit, a conditional conclusion, and a next step with proposed limits and success/stop conditions. Missing or conflicting evidence stays visible. A complete report is not proof that a recommendation is correct.

If the answer is generic, provide the constraint or evidence most likely to change it. If it is too long, ask for a concise brief. No special connector is required; current research depends on tools available in your chat.
