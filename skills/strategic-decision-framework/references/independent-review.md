# Independent Decision Review

Use two reviewers with bounded, distinct jobs. The main agent owns the final brief. Do not create one agent per lens or use majority voting.

## Shared packet

Give each reviewer the decision, options (including the status quo), goals, hard constraints, deadline, user preferences clearly labeled as preferences, and the same raw evidence with source locations and dates. Include only relevant material. Do not supply the main agent's proposed winner or the other reviewer's response before their first independent pass.

## Evidence reviewer

Check the evidence for each option. Return up to five material findings with source locations: supported claims, unsupported claims, conflicting sources, sample limits, and missing evidence. Explain which findings could change feasibility or confidence. Do not invent facts or independently contact stakeholders. Use additional research only within the user's authorized scope and available tools.

## Challenge reviewer

Develop the strongest plausible case against the user's apparent preference, or against committing now if no preference is known. Identify constraint violations, opportunity costs, preventable failure modes, and a disconfirming observation. Return up to five findings, each supported by a source or labeled as an assumption. Do not invent customer views or force an opposing case when evidence clearly favors one path.

## Reconcile

Read both returns and verify material claims against their sources. Resolve disagreements by evidence quality and constraints. Keep genuine uncertainty visible and explain whether review changed the conclusion, confidence, or next test. Agreement among agents is not independent external evidence. Use at most one targeted follow-up per reviewer when a material question remains; then report unresolved points.

If delegation is unavailable or disallowed, run evidence and challenge passes sequentially. State that these were checks by the same agent, without implying independent reviewers ran. Return one concise brief, not three separate reports. These reviews support analysis and do not authorize execution of the business decision.
