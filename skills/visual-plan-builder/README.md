# Visual Plan Builder

Ask Maker Labs to turn a complex request into a standalone HTML plan you can review.

Try "Create a visual plan for this research project before starting." Supply the desired outcome, constraints, source material, and any decisions already made. For an authorized end-to-end task, say "Make the visual plan, then execute it."

The result includes assumptions, alternatives, a recommended path, workflow, sources, risks, and success checks. Approval status reflects what you actually authorized. The approval box is text; reply in chat to approve or revise.

Plans need file creation and a browser or preview to view. When those tools are unavailable, the skill provides Markdown or HTML source and explains the limitation. No external fonts, scripts, or special connectors are required. It can be used independently of the other Maker Labs skills.
