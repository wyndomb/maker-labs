# Review Checklists

Use these checks after the user approves a visual plan and the work is executed. Pick only the checks that fit the task.

## Universal Checks

1. The final output matches the approved goal.
2. The final output uses the approved path or explains why it changed.
3. Human approval points were respected.
4. Risks were addressed or carried forward as caveats.
5. The output includes the promised deliverables.
6. The output avoids anything listed in "Do Not Do."
7. Any unresolved assumptions are visible to the user.

## Newsletter Or Paid Post Checks

1. Reader problem is clear.
2. When paid content is requested, its promised practical deliverable is present.
3. When a free/paid model applies, the boundary is clear.
4. The user's supplied voice and platform preferences are followed.
5. Generated prose follows the user's punctuation preferences, with no em dashes by default outside preserved quotations.
6. No banned artificial contrast construction.
7. No jargon prohibited by the user's supplied rules; no private rule file is assumed.
8. Metrics, if used, include context or limitation.

## Research Checks

1. Sources match the planned source types.
2. Current claims were verified when needed.
3. The answer separates facts, interpretation, and recommendation.
4. Uncertainty is named.
5. Links or citations are included when research was used.

## Agent Or Workflow Build Checks

1. Inputs and outputs match the plan.
2. File paths match the approved structure.
3. The smallest useful version works before extra features are added.
4. Human approval points are preserved.
5. Failure cases have checks or recovery notes.
6. Validation was run where possible.

## Content Repurposing Checks

1. Each platform has a distinct angle.
2. The source idea is preserved.
3. The output does not sound like a compressed version of the original.
4. Voice and formatting match the platform rules.
5. Repeated hooks or repetitive openings are removed.

## Dashboard Or Data Checks

1. Raw data and visual summary are not mixed in a confusing way.
2. The first screen answers the main planned question.
3. Chart choices fit the data.
4. Missing or messy data is called out.
5. Formulas, filters, or calculations were tested if applicable.

## Decision Support Checks

1. The decision is stated plainly.
2. Options are compared against the planned criteria.
3. The recommendation names the tradeoff.
4. Reversibility and risk are visible.
5. Next action is concrete.
